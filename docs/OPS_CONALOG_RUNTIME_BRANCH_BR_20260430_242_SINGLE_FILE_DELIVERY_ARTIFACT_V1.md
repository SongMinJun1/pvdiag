# OPS_CONALOG_RUNTIME_BRANCH_BR_20260430_242_SINGLE_FILE_DELIVERY_ARTIFACT_V1

## Summary
- This patch adds the generated single-file delivery path for the PV panel fault/precursor diagnosis runtime.
- The professor-facing artifact is `release/conalog_full_runtime_v1/pvdiag_single.py`.
- The file is generated by `tools/build_pvdiag_single_py.py`; it is not hand-maintained.
- Runtime semantics are unchanged.

## Why
- The project remains modular internally, but handoff requires one Python file that can be executed from VS Code, Jupyter, or a terminal.
- The single file embeds the small Python/package payload and restores it to a temporary runtime folder at execution time.
- External Python dependencies and input CSV data stay outside the generated file.

## Included Payload
- `release/conalog_full_runtime_v1/package/app/*.py`
- `release/conalog_full_runtime_v1/package/pv_ae/*.py`
- `release/conalog_full_runtime_v1/package/research/**/*.py`
- small package artifacts under `release/conalog_full_runtime_v1/package/artifacts`
- `release/conalog_full_runtime_v1/package/requirements.txt`

## Explicit Exclusions
- `release/conalog_full_runtime_v1/package/runtime/windows_x64/**`
- batch/PowerShell wrapper scripts
- `__pycache__` and bytecode files
- external libraries such as `pandas`, `numpy`, `torch`, `openpyxl`, and `tqdm`

## Generated Outputs
- `release/conalog_full_runtime_v1/pvdiag_single.py`
- `release/conalog_full_runtime_v1/pvdiag_single_manifest_v1.json`

## Validation Contract
- `python3 -m py_compile pv_ae/panel_day_engine.py`
- `python3 tools/build_pvdiag_single_py.py`
- `python3 -m py_compile release/conalog_full_runtime_v1/pvdiag_single.py`
- `python3 release/conalog_full_runtime_v1/pvdiag_single.py --single-self-test`
- single-file runtime output must match modular runtime output on key CSV row counts and schemas.
- master report and detailed xlsx must exist in both output roots.

## Operator Boundary
- This is a delivery/reproducibility patch, not an algorithm patch.
- No truth rows, thresholds, engine semantics, or operator-facing diagnosis rules are changed.
- `pvdiag_single.py` defaults to `--workspace-retention result-only` when the caller does not specify a retention mode, to avoid recreating large disposable runtime workspaces.
